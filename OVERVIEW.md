# Штаб

Штаб собирает проекты, области и сессии Paseo, интерактивные ответы GenUI, артефакты,
мониторинг воркеров и служб, расход и квоты моделей в одном интерфейсе.

Области можно группировать и перемещать между проектами. Сессии области - это
вкладки агентов и терминалов. В панели области есть фильтр открытых сессий и
переписка закрытых агентов. В Штабе также можно смотреть документы и клонировать
репозитории из подключенных GitHub и GitLab.
Интерактивные ответы работают на телефоне и компьютере.

Настройка выполняется на выбранном хосте Paseo. Нужен Paseo 0.15.0 или новее.
Интеграции с Telegram, облачным хранилищем, воркерами и службами настраиваются
отдельно. Плагин читает локальные файлы и учетные данные подключенных CLI,
а серверные обращения к провайдерам выполняются на хосте.

Панель лимитов различает квоты подписок, баланс API и локальную статистику.
Gemini API читает живые ограничения Service Usage по моделям отдельно от
Antigravity. В карточке есть настройка проекта и справка по подключению,
OAuth, API, биллингу и кредитам Pro. Эта же справка доступна агентам через
инструмент hq_gemini_help. Расход через Monitoring пока не подключен.
При отсутствии доступа или данных интерфейс сообщает об этом явно.
